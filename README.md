## Omics-in-practice:
This repository includes all the scripts from the computational analysis of the Omics in Practice course (NWI-BM094) of Radboud University within the context of the Master's program Medical Epigenomics. The research project involves studying the impact of the drug treatment on the acute myeloid leukemia (AML) cells using the approach of multi-omics. The repository will include scripts for RNA-seq analysis, epigenomic analysis, proteomics, and data integration.
